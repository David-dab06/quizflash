# QuizFlash — jeu web

Jeu de quiz de culture générale en français, adapté aux mobiles. Aucun framework ni installation n'est nécessaire.

## Fichiers
- `index.html` : page du jeu
- `style.css` : design responsive
- `game.js` : questions, chronomètre, score et partage
- `privacy.html` : modèle de page de confidentialité

## Publier gratuitement avec GitHub Pages
1. Connectez-vous à https://github.com depuis votre navigateur.
2. Appuyez sur **New repository**.
3. Nommez le dépôt `quizflash` et choisissez **Public**.
4. Ajoutez les quatre fichiers de ce dossier à la racine du dépôt (Add file → Upload files).
5. Ouvrez **Settings → Pages**.
6. Dans **Build and deployment**, choisissez **Deploy from a branch**.
7. Sélectionnez `main` et `/ (root)`, puis **Save**.
8. Attendez la publication. GitHub affichera l'adresse de votre site dans la section Pages.

## Avant AdSense
- Remplacez `contact@example.com` dans `index.html` et `REMPLACEZ-PAR-VOTRE-EMAIL` dans `privacy.html`.
- Publiez un site complet, accessible et utile. Ajoutez du contenu original autour du jeu (règles, catégories, explications et nouvelles séries de questions).
- Vérifiez les exigences AdSense et les règles de consentement/cookies applicables à vos visiteurs.
- Ne collez pas de code publicitaire avant l'approbation. Après approbation, insérez le code officiel fourni par AdSense et respectez ses règles.
- GitHub Pages héberge le site mais ne garantit pas l'approbation AdSense. Un domaine personnalisé peut être utile, mais n'est pas automatiquement obligatoire.

## Tester
Ouvrez `index.html` dans un navigateur ou publiez-le avec GitHub Pages. Le jeu est conçu pour mobile et ordinateur.
